# CS2 UNTITLED

CS2 UNTITLED is the user-confirmed name of this CS2 demo-analysis application. User-facing navigation, login, Home, footer, document title and report attribution use this name.

Players and teams import `.dem` match files and review recorded match events and statistics. The public Home introduces the application and leads to Steam sign-in or the existing guest flow. It presents the capabilities already implemented; it must not invent results, professional comparisons, model accuracy or performance claims.

The confirmed Home workflow is: upload a demo → 2D replay → heatmap → economy → analysis → opening routes → PDF reports. Scoreboard remains an application feature but the user removed its Home preview. The two analysis tools are separate adjacent previews so that both supplied recordings are visible.

The user supplied `Media/demoweb1.mp4` for the main demonstration and seven GIFs in `Media/` for feature previews. Originals remain unchanged. Derived, web-sized assets and their source manifest live in `frontend/public/media/home/`.

The user restored the original Home slogan: “See the whole round before judging one moment” / “ดูให้ครบทั้งรอบ ก่อนสรุปจากจังหวะเดียว”. Home omits the Watch-the-demo navigation link, feature-introduction description and playback hint, and footer tagline at the user's request.

The existing navy, orange and cyan visual system, Chakra Petch headings, Anuphan body, Thai/English content and light/dark themes are the visual authority. The reference feature-card screenshot supplies a structural example; its wording, colors and unrelated product claims are not authorized content.

This task extends the existing Home and updates visible branding. It does not replace application behavior, authentication, permissions, stored match data or the existing visual identity. Route-specific composition and review evidence belong in `.impeccable/surfaces/frontend-src-homepage-tsx.md`.

Home precedes sign-in: visitors opening a protected app URL see Home first, then use its entry action to reach Login. The internal destination is preserved through sign-in. Logging out returns Home; the Login brand links Home. Direct Login links remain usable, including Steam error returns. The Login radar has no source-caption copy.

Personal Stats prioritizes the player's core statistics and recent matches, as confirmed by the user. Its profile hierarchy takes inspiration from Leetify's published profile organization while using CS2 UNTITLED's own palette, typography, data and layout. A horizontal player identity leads to the match-range selector, a six-metric strip and recent-match table. Duels, Clutch and side roles sit in a second category; maps and weapons sit in a third. Ratings retain their calculation provenance. This refinement uses the existing player-profile API and Steam authentication.

Match review includes a playback-synchronized latest-five kill feed with seek actions and Steam avatars beside scoreboard names. Heatmap keeps the smooth Canvas density view; hover, touch or keyboard inspection shows filtered counts and units for the selected area. The user removed the alternate Area Grid view. Inspection uses fixed aggregation areas whose radar-image pixel dimensions appear in the tooltip. Position values approximate combined player-seconds from recorded tick intervals, cap recording gaps and fall back to sample counts when timing is unavailable. Avatars load separately from match statistics and use initials when unavailable. Heatmap displays the demo filename above the map.

Personal Stats includes an ECharts trend and period comparison below the core metrics and before category navigation and match history. ADR is selected by default; KAST and calculated Rating 1.0 are available. A map filter and 3-, 5- or 10-match period selector compare the latest two complete, equal-sized, disjoint windows within available profile data. The table shows per-match means, signed changes and each period's match/round counts; KAST changes use percentage points. Missing measurements suppress the affected comparison, and insufficient matches show the required count. Pointer, touch and keyboard inspection reveal per-match details. Periods follow demo import order, with that limitation disclosed; changes do not establish permanent skill gains. This replaces the SVG rolling-average chart, uses the existing ECharts dependency and themes, and adds no raster assets.

Settings is available from the signed-in profile menu. Steam users can save a Game Authentication Code and recent Match Sharing Code as encrypted, write-only values, disconnect locally, and request manual sync of at most three matches through RQ into the existing parse queue. Saving does not validate codes; sync verifies account membership before accepting bounded Valve replay downloads and CS2 demo data. There is no automatic sync scheduler. The current local server lacks `STEAM_API_KEY`, `STEAM_GC_SERVICE_TOKEN` and `STEAM_GC_REFRESH_TOKEN`, so readiness is false and Sync remains disabled; live importing has not been verified. Operator setup is documented in `integrations/steam-gc/README.md`.
